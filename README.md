## Introduction
This is an extension project from the paper [MICE for CATs: Model-Internal Confidence Estimation for Calibrating Agents with Tools](https://arxiv.org/abs/2504.20168). In  original paper, the authors focused on tool calling capabilities of LLMs. In our extension, we make decision for LLMs to answer, clarify, and abstain based on its internal confidence estimation.

## What each folder is

1. original_nb_data - In original_nb_data, we have the notebooks that we developed and ran using Google Colab. You are welcome to copy these notebooks and the data we used to your own drive and use Colab's runtime to replicate our workshlow, but this will require you to do some adapting.

2. local_execute - We've made some changes to our original notebooks so that you can replicate our workflow locally, and added some additional scripts to streamline the process. You have the option to run the training and evaluation part only, which is less demanding on compute resources.

**More information can be found in the respective README files in each folder**
